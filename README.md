# ML_TDM_MEPES
This project presents a framework for continuous FDI threat detection and mitigation in Modern EPES. The repository contains  scripts to evaluate the performance of FDI attack on sensor measurements in smart grids, with an ML-enabled detection module, enabling live mitigation of FDI attacks.
